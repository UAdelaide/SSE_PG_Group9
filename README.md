# SSE_PG_Group9
Steps to excute the application:
1. git clone https://github.com/UAdelaide/24S1_WDC_PG_Group_5.git
2. install docker from this link https://docs.docker.com/desktop/setup/install/windows-install/
2. In terminal run the following commands:
   i. npm i
   ii. service mysql start
   iii. mysql < sse.sql
   iv. npm start
3. Go to the browser and use this url http://localhost:8080/
